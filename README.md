# EDA - Dataset de Pokémon

Análisis exploratorio de datos (EDA) del dataset de Pokémon (800 registros)
como parte de la actividad individual de la materia Inteligencia Artificial.

## Contenido
- `main.ipynb`: notebook con el análisis completo (ejecutado).
- `Pokemon.csv`: dataset utilizado.

## Análisis realizado
- Identificación de tipos de variables.
- Estadística descriptiva.
- Relaciones entre variables (matriz de correlación).
- Visualizaciones: histograma, heatmap de correlación y gráfico de barras.

## Herramientas
Python, pandas, matplotlib, seaborn.
